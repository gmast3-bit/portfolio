# Gulshan Mastonova: Professional Portfolio

Personal portfolio website built with [Quarto] (https://quarto.org) and hosted on GitHub Pages for PA 446: Coding for Civic Data Applications (Fall 2026).

**Live site:** https://gmast3-bit.github.io/portfolio/

## Site structure

| File / folder | Purpose |
|---|---|
| `_quarto.yml` | Site settings: project type, output folder, navbar, theme, fonts, colors, and PDF resources |
| `index.qmd` | About page built with Quarto's `trestles` about template: photo, bio, and contact links |
| `project.qmd` | Past Project Showcase: research poster description, skills, callout box, download button, and PDF preview |
| `styles.css` | Custom stylesheet for headings, buttons, the PDF preview frame, and About page links |
| `images/` | Profile photo |
| `files/` | Downloadable PDFs (resume and project poster) |
| `docs/` | Rendered website that GitHub Pages publishes (generated by `quarto render`) |

## Design choices

- **Theme:** Flatly, a clean Bootswatch theme suited to a professional portfolio.
- **Colors:** UIC navy (`#001E62`) for the navbar and headings and UIC red (`#D50032`) for links and buttons, to match university branding.
- **Typography:** Base font size set to `1.05rem` and headings to `1.6rem`. Relative units let text scale with each visitor's browser settings, which supports accessibility.
- **Advanced features:** A separate custom CSS stylesheet and a callout box highlighting the project's key finding.

## How to build

```bash
quarto render
```

The site renders into `docs/`, which GitHub Pages serves from the `main` branch.
